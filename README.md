# Failed Banks Analysis
#### Performing a simple analysis of data regarding all failed banks in the US since the year 2000.
<br>

### Process Overview
The project was created using Power BI. The data is acquired dynamically from the Failed Bank List compiled by the US Federal Deposit Insurance Corporation (FDIC): https://www.fdic.gov/bank-failures/download-data.csv
<br><br>
The steps of the project included:
<ul>
  <li>cleaning and transforming data</li>
  <li>analysis</li>
  <li>visualization</li>
</ul>
All of these steps were done in Power BI.
